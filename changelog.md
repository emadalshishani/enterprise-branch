# Changelog

## Initial Branch Network Lab

### Added

* Branch network architecture documentation
* VLAN 50 and VLAN 60 segmentation
* VRRP gateway redundancy
* Redundant Layer 2 access connectivity
* Juniper SRX connectivity
* Static routing between the SRX and Layer 3 switches
* VRRP gateway failover testing
* Branch PC to SRX connectivity testing
* Failure and recovery verification
* Documentation of the current static-routing limitation

### Verification

The Branch network was tested under normal operation and during gateway failure scenarios to verify VRRP failover and identify limitations in the current routing design.
